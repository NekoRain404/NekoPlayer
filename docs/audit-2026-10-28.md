# NekoPlayer 全面审计报告（2026-10-28）

本报告记录 2026-10-28 对 NekoPlayer 0.1.0 的功能、安全、性能、正确性、逻辑一致性与体验审计。
证据来自源码阅读、静态分析、干净构建、CTest 全量运行和针对性复现实验。
标注约定：**实测** = 本机复现或命令输出；**代码确认** = 代码路径与触发条件已确定；**需真机** = 依赖真实 GPU/桌面会话。

## 一、总体结论

分层清晰（playback / session / input / preview / ui），mpv 命令全部走 argv 数组，路径校验严格，
持久化使用原子写，重入与生命周期保护写得谨慎。主要问题集中在验证链路、事件竞态、
数据真源分裂、缩略图管线、键盘可访问性和文档漂移。

## 二、P0（优先修复）

### P0-1 测试套件在正常桌面 locale 下崩溃（实测）
- 证据：`LC_ALL=C` 下 71/71；默认 `en_US.UTF-8` 下 39/84 失败、6 个 SIGSEGV。
- 根因：测试进程不设置 `LC_NUMERIC=C`（生产代码在 `src/main.cpp:26-28` 设置），libmpv 在非 C
  数值 locale 下打印 `Non-C locale detected. This is not supported.` 并初始化失败，
  `mpv_create()` 返回 NULL；测试辅助函数 `tests/decoding_test.cpp:14` 对空句柄调用
  `mpv_get_property_string()`，触发 SEGV（`mpv_get_property+29`，访问 0x48）。
- 影响：README 记录的 `ctest --preset debug` 在普通桌面必定失败，并产生 core dump。
- 修复：所有 CTest 测试注入 `LC_ALL=C`/`LANG=C`；测试辅助函数判空；`ctest` 文档命令同步。

### P0-2 Stop 可能被排队事件撤销（代码确认）
- `mpvcontroller.cpp:317-325` 清空 entry 映射，但 `mpvcontroller_events.cpp:221` 对未知 entry
  回退到当前 generation；EOF 事件已排队时，Stop 后仍会 `emit playbackFinished()`，
  而 `PlaylistController::playbackQueued_` 未清除，导致自动跳下一项。
- `handleFileLoaded()`（events:249-269）会接受不在任何映射中的 entry，Stop 或新 open 期间
  到达的 FILE_LOADED 会把旧文件标成 active，`fileLoaded` 处理器读到新路径。
- 修复：被 Stop 失效的 entry 建墓碑；Stop 重置 `playingEntry`；FILE_LOADED 必须匹配当前
  generation 或恢复加载；`stopRequested` 清 `playbackQueued_`。

### P0-3 媒体暂时不可用会永久删除轨道偏好（代码确认）
- `TrackPreferenceStore::matchesFingerprint()` 要求文件存在且 size/mtime 一致；
  `SessionManager::saveTrackPreferences()`（sessionmanager.cpp:355-363）每次保存前删除不匹配项，
  `load()` 也按同一规则丢弃。
- 影响：U 盘/网络盘未挂载时启动一次，之后任意保存即永久丢失这些媒体的音轨/字幕记忆。
- 修复：区分"文件暂时缺失（保留）"与"文件被替换（丢弃）"。

### P0-4 辅助存储错误锁存（代码确认）
- `playbackhistorystore.cpp:126-136` 单条坏记录同时返回有效条目与 error；
  `sessionmanager.cpp:98` 永久保存 `historyError_`，此后不再记录历史（:164-166），
  `save()` 把它当作会话保存失败（:160-166），关闭时误报"会话未保存"。
- 修复：致命错误（schema/版本）与单条无效分离；坏条目丢弃后重写；会话保存只返回会话错误。

### P0-5 渲染上下文恢复边界（代码确认）
- `prepareForRendererReset()` 只在 active 时快照，加载中丢上下文无法恢复。
- 恢复加载未登记 pending open；其 `VO_INIT_FAILED` 被当作预期重置吞掉，无错误无重试。
- `mainwindow.cpp:250-254` 在渲染重建期间追加文件会跳过 `resumeAfterRendererReset()`。
- 修复：恢复快照与 active 解耦；恢复加载登记并区分失败；ready 时只要存在 recovery 就恢复。

### P0-6 缩略图管线（代码确认）
- `avformat_open_input(..., nullptr, nullptr)` 无协议/格式白名单、无 rw_timeout、无 probe 上限；
  interrupt 回调没有墙钟 deadline，单线程池可能永久阻塞，退出时 `waitForDone()` 卡死。
- 解码循环从关键帧到目标逐帧 `sws_scale`（4K 5s GOP 约 300 次全尺寸转换）。
- 每次 hover 请求先 `cancel()`，拖动时间条时请求永不收敛。
- 修复：本地协议白名单 + 超时 + probe/像素上限；只转换最终帧；请求防抖与秒级量化。

### P0-7 全局快捷键破坏键盘可访问性（实测 harness）
- 所有动作默认 `Qt::WindowShortcut`（windowactions.cpp:51-57）。
- Tab 被占为播放信息开关（:258-259），焦点遍历失效。
- ↑/↓ 被占为音量（:129-130），播放列表方向键不移动选择。
- 空格被占为暂停（:77），聚焦按钮无法用空格激活。
- 修复：缩小快捷作用域；给列表/按钮补 `ShortcutOverride`；Tab 换键或限定到视频区。

### P0-8 英文翻译缺失（实测）
- `lupdate` 提取 368 条，`NekoPlayer_en.ts` 仅 315 条，104 条源码字符串无译文；
  多个完整上下文缺失。README 仍宣称"315 条全部完成"。
- 修复：重新提取、补齐译文、CI 校验；再更新 README。

## 三、P1（重要）

### 数据与正确性
- Shuffle+Repeat All 只向前回绕（playlistcontroller.cpp:74-83 对比 :437-471）。
- 非空队列 `currentIndex == -1` 时保存播放列表必定失败（m3u8store.cpp:94-97）。
- "清空最近播放"不清续播与首页"继续观看"（recentmediamenu.cpp:63-69）。
- 截图失败完全静默（screenshotmenu.cpp:36-40）。
- `seekAbsolute` 在 duration 未知时把目标钳到 0（mpvcontroller.cpp:343-349）。
- 被 Stop 取消的命令回复仍上报错误（mpvcontroller_events.cpp:152-166）。
- `VideoWidget::failed_` 粘滞，瞬时 GL 失败后永久拒绝打开（videowidget.cpp:46-85）。
- `playFinished` 在 emit 后不复查 revision（playlistcontroller.cpp:315-338）。
- `MpvController::handle()` 公开裸句柄且可为 NULL（mpvcontroller.h:46）。

### 安全加固
- 带凭据/签名 query 的网络 URL 明文写入 0644 配置文件与目录 0755（sessionstore.cpp:295 等）。
- `ytdl` 默认开启，系统存在 yt-dlp 时可被拉起（mpvcontroller.cpp:11-23）。
- 打开外部 `.m3u8` 立即自动播放，接受 loopback/私网地址（mainwindow.cpp:399-401）。
- 多处 `readAll()` 无大小/类型上限（m3u8store.cpp:41、sessionstore.cpp:27 等）。
- 文件名解码后直接进入 `QLabel` AutoText 与窗口标题（welcomepanel.cpp:221 等）。
- 构建未请求 PIE/RELRO/stack-protector/FORTIFY；libmpv/FFmpeg 无版本下限（CMakeLists.txt:18-35）。

### 性能
- 缩略图逐帧缩放与请求风暴（见 P0-6）。
- 批量删除逐行 beginRemoveRows，O(k·n)（playlistmodel.cpp:182-193）。
- 玻璃预览每个滑块 tick 重建全量 QSS（preferencesappearancepage.cpp:80-99）。
- 每次 tracksChanged/换项同步重写偏好与历史（sessionmanager.cpp:32-35,63,190,332）。
- `time-pos` 每帧触发 stateChanged 到约 10 个槽（mpvcontroller_events.cpp:82-111）。
- 会话启动/退出多次全量解析与写入（sessionstore.cpp:20-45,155-312）。
- 排序在 GUI 线程做 O(n log n) 本地化比较（playlistmodel.cpp:204-225）。
- 每行注册 QPersistentModelIndex（shuffleorder.cpp:26-33）。
- 文件夹扫描超限整体放弃、排序不可取消（mediafolderscan.cpp:13,93-95）。
- 视频渲染更新无合并（videowidget.cpp:116-141）。

### 体验 / 一致性
- 错误只进状态栏 2 秒，小窗模式完全不可见（mainwindow.cpp:474-488,652-661）。
- 任意 mpv 命令失败都显示"无法播放：…"（mainwindow.cpp:476）。
- 外观预览取消不回滚 glass 属性（preferencesdialog.cpp:261-264）。
- 偏好标签固定 128px，英文被截断（preferencesformlayout.cpp:15,23）。
- 快速操作 Ctrl+K 不可发现（quickactionsdialog.cpp:55-59）。
- 字幕/设置菜单重复 Alt+S（trackmenus.cpp:31 对比 windowactions.cpp:278）。
- 空闲时后退/前进仍启用并弹 OSD（mainwindow.cpp:449-465）。
- 播放列表提示与单击/过滤状态矛盾（playlistpane.cpp:88-89）。
- `applyTheme` 仅测试使用；QSS `opacity` 规则无效。
- 小窗/全屏切换在真实 Wayland 下 5 个子用例失败，状态只在动画结束后同步。

## 四、P2（文档与仓库）

- 版本号 5 处重复（CMakeLists.txt:2、main.cpp:34、appearancepreferences.cpp:148、metainfo.xml:23、PKGBUILD:3）。
- 打包文档声称 `sha256sums=('SKIP')`，PKGBUILD 实际固定 checksum 且指向 release。
- README 写 64/64、verification 写 70/70，实际注册 84 个测试；3 个窗口测试只编译不注册。
- README 称 FFmpeg 仅测试需要，实际无条件链接；LinguistTools 未提及。
- `file://host/path` 在 normalize 接受、拖放拒绝，行为不一致。
- 无单实例；无 CI。
- M3U8 丢弃 `#EXTINF`/`#EXT-X-*`，HLS 分片被展开为队列项，另存会丢元数据。
- metainfo homepage 指向个人主页；图片播放支持不一致；README 缺少 Ctrl+K 等快捷键。

## 五、功能缺口（对标 PotPlayer）

1. 字幕搜索/下载与完整字幕样式（颜色、描边、阴影、编码回退）。
2. 音频均衡器与视频滤镜（锐化、降噪）。
3. 媒体库/监视文件夹与章节缩略图。
4. 倍速/延迟按媒体记忆。
5. 快捷键自定义。
6. 网络超时/重连与受控的 yt-dlp。
7. 睡眠定时器、单实例。
8. 截图命名模板。
9. 图片播放的完整支持或明确拒绝。
