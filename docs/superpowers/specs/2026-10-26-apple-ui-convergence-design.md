# Apple 风格 UI 收敛与快速操作设计

日期：2026-10-26  
分支：`main`
基线：`7cfa700`（`main` 当前 UI 收敛验证基线）

## 目标

把 NekoPlayer 现有的主题、毛玻璃、播放控制、播放列表、设置页和菜单收敛为一套稳定的视觉与交互语言，并补充一个键盘优先的快速操作入口。播放器仍以视频为视觉主角，UI 负责层级、反馈和导航，不新增播放引擎或第二条渲染路径。

## 当前上下文

当前分支已经具备：Dark/Light/System、五种强调色、可调玻璃透明度与柔化程度、统一 PreferencesCoordinator、首页历史/续看、缩略图预览、逐帧、网络播放、播放列表搜索、交互偏好和 mini-player。最近几轮提交已把菜单、设置页、控制条、侧栏和首页接入统一玻璃材质；当前工作区的 `docs/skills.md` 是用户已有修改，不得覆盖或纳入本项目提交。

## 设计原则

### 视觉层级

只保留四级表面：

1. `canvas`：窗口和视频之外的基础背景。
2. `surface`：侧栏、设置页、状态栏和普通控件所在的主面板。
3. `raisedSurface`：菜单、弹出列表、对话框和悬浮卡片。
4. `accentSurface`：播放按钮、选中项、进度和焦点状态。

每一层由 `AppearanceTokens` 生成，组件不再自行拼接颜色、透明度或渐变。玻璃开启时只改变窗口及非播放控制面板的填充和边缘层次；关闭时使用同一 token 的不透明 fallback。普通与全屏播放控制栏始终使用不透明 `surface`，玻璃开关只改变控制栏之外的界面材质；视频帧不加透明度、不模糊、不复制到 CPU。

### 间距、尺寸和排版

沿用 4 px 基础单位，常用间距固定为 4/8/12/16/24。交互控件统一最小高度与点击热区；标题、正文、辅助文字只保留有限字号层级。设置页、播放列表、首页卡片和 transport 不再各自定义一套间距。

### 交互反馈

所有可交互控件都要覆盖默认、悬停、按下、焦点、选中、禁用状态。焦点不能只依赖颜色；键盘焦点必须有清晰边框或光晕。动画只用于出现/消失、悬停和状态切换，默认 140–180 ms，不能影响视频播放或引入持续轮询。

### Wayland 与性能边界

目标平台是 Wayland。真实合成器支持的窗口外背景模糊可以保留，但应用内部不实现 GPU backdrop blur。玻璃效果不得安装到 `VideoWidget`，不得改变 libmpv/OpenGL/HDR/硬解路径。所有自绘层必须缓存静态背景，避免在播放进度 tick 中重建渐变、字体或路径。

## 子项目 A：视觉与交互统一

### A1. 材质 token 与 QSS 契约

- 扩展 `AppearanceTokens`，明确 canvas/surface/raised/accent 四级表面及统一的边框、焦点、禁用和 hover 语义。
- 将窗口、菜单栏、状态栏、设置页 tab/pane、playlist、首页卡片和输入控件映射到四级表面；transport 固定使用不透明 `surface`，普通与全屏材质一致。
- 移除重复的控件内颜色和硬编码透明度；保留确实属于视频 OSD 的局部样式，但其颜色从 token 获取。
- 毛玻璃开关、透明度和柔化程度只进入 `panelFill()` 等集中函数；不得在单个 widget 里解释这些设置。

### A2. 布局与密度

- 设置页：统一页边距、标签列宽、表单行高度、tab 高度和按钮组间距。
- 播放列表：统一标题栏、搜索框、行高、选中行和空状态；窄窗口保持可用热区，不让内容跳动。
- Transport：统一主播放按钮、次级按钮、时间、音量和窗口动作的组间距；全屏与普通窗口沿用同一组 QAction 和状态。
- 首页：统一品牌、最近播放、继续观看和入口按钮的卡片节奏；无媒体时不显示多余边框。

### A3. 交互细节

- 焦点、悬停、按下和禁用状态使用同一套对比度规则；浅色主题也必须满足正文 4.5:1、边界 3:1 的目标。
- 菜单、组合框、搜索框和按钮使用一致的内边距、圆角、箭头/勾选图标和键盘导航。
- 全屏 transport、定位反馈、缩略图预览和 mini-player 的出现/消失动画采用相同时间曲线；不改变现有行为语义。
- 对可点击但没有明显文本的图标补充 tooltip、accessible name 和键盘路径。

## 子项目 B：快速操作面板

增加一个可选的键盘优先 `QuickActionsDialog`，默认快捷键 `Ctrl+K`，不改变现有快捷键：

- 从实时 `QAction` 树读取动作，复用现有文字、图标、启用状态和快捷键，避免维护第二份命令表。
- 输入框支持不区分大小写的模糊/包含过滤；结果按菜单分组或动作上下文显示。
- Enter/双击触发当前动作，Esc 关闭，箭头键移动选择；动作不可用时显示但不能触发。
- 对播放控制、定位、主题、语言、播放列表显示、截图和设置入口提供统一搜索入口。
- 对话框为非模态、无激活抢焦点之外的副作用；关闭后焦点回到打开它的控件。
- 面板使用 raisedSurface 材质，不覆盖视频，不新增 blur renderer；无输入时不创建后台任务。

## 明确不做

- 不引入 Vulkan、Qt Quick、第二播放引擎或皮肤系统。
- 不把真实视频帧复制到 CPU 做模糊或缩略图以外的 UI 合成。
- 不在本轮增加插件、媒体库数据库、云同步、字幕编辑器或复杂工作区系统。
- 不在未完成真实 Wayland 验收前宣称 Apple 级视觉已经完成。

## 验收标准

### 自动化

- Appearance/QSS 测试覆盖四级 surface、透明/不透明分支、焦点/禁用/选中状态和 VideoWidget 隔离。
- Preferences/Transport/Playlist 测试覆盖统一尺寸契约、状态切换和窄宽度行为。
- QuickActions 测试覆盖实时 QAction 去重、过滤、不可用动作和触发回调。
- Debug 非窗口 CTest、code-size、clang-format 和 scoped diff check 通过；窗口行为测试继续按用户要求跳过。

### 人工 Wayland

- Dark/Light、玻璃开关、至少两种 accent 在 100% 与 175% 缩放下检查首页、播放、播放列表、设置页、菜单、全屏和 mini-player。
- 检查视频区域不因玻璃或底栏出现位移，控件不闪烁、不重叠，焦点和键盘导航可见。
- 检查合成器模糊只影响窗口背后的桌面，不改变视频像素；记录 compositor、Qt 平台插件、分辨率和缩放。
