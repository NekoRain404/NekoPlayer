# NekoPlayer

以 **C++20 / Qt 6 + libmpv** 为基础，目标是做出接近 PotPlayer 的桌面播放体验：打开即播、完整快捷键与右键菜单、灵活的字幕/音轨选择、播放列表和可理解的设置。

当前为可播放的早期版本：Qt Widgets + QOpenGLWidget 嵌入 libmpv，提供深色紧凑控制区、菜单、右键菜单和本地播放列表。本地媒体可通过打开、添加、拖放或命令行进入队列；支持 M3U8 播放列表读写、暂停、停止、时间定位、章节导航、上一项/下一项、音量、静音、全屏、音轨切换、内嵌字幕选择、外挂字幕加载、字幕显示设置、画面比例／旋转、亮度／对比度／饱和度／色调／伽马调整、倍速与音频／字幕延迟调整。队列、音量、硬解、字幕显示、色彩调整、倍速与延迟、窗口偏好及最近 100 个媒体文件的续播位置可在正常退出后恢复；F5 打开按播放、音频、字幕分组的偏好设置，F6 直接定位到字幕页。

## 构建与检查

需要 CMake 3.25+、Ninja、支持 C++20 的编译器、Qt 6.5+ Core/Widgets/OpenGLWidgets、libmpv 开发库和 pkg-config。原生 Wayland 测试还需要 Qt Wayland 平台插件、可用的 Wayland 桌面会话及 Qt Test、FFmpeg。Xvfb、xvfb-run 和 Openbox 仅用于显式的 X11 CI 回归。仅构建播放器可传入 `-DBUILD_TESTING=OFF`。当前使用 Linux/pkg-config；Windows SDK 查找与打包尚未配置。

```bash
cmake --preset debug
cmake --build --preset debug
ctest --preset debug
./build/debug/NekoPlayer
./build/debug/NekoPlayer '/path/电影 example.mkv'
./build/debug/NekoPlayer first.mkv second.mkv third.mkv
./build/debug/NekoPlayer --check-backend
./build/debug/NekoPlayer --no-config
```

仅运行无需桌面会话的后端检查（当前按用户要求跳过 GUI 测试）：

```bash
ctest --test-dir build/debug -R '^(code-size|backend-startup|resume|media-information|media-report|frame-step|ab-loop|decoding|subtitles|playback|playlist|playlist-edit|playlist-modes|playlist-shuffle|tracks|session|tuning|navigation|playback-time|file-drop|video-presentation)$' --output-on-failure
```

内存检查预设，以下命令仅构建和执行非 GUI 集成测试：

```bash
cmake --preset sanitizers
cmake --build --preset sanitizers --target resume_test media_information_test media_report_test frame_step_test ab_loop_test decoding_test subtitles_test playback_test playlist_test playlist_edit_test playlist_modes_test playlist_shuffle_test tracks_test session_test tuning_test navigation_test playback_time_test file_drop_test video_presentation_test
ctest --test-dir build/sanitizers -R '^(resume|media-information|media-report|frame-step|ab-loop|decoding|subtitles|playback|playlist|playlist-edit|playlist-modes|playlist-shuffle|tracks|session|tuning|navigation|playback-time|file-drop|video-presentation)$' --output-on-failure
```

在没有 Wayland 桌面会话的 CI 上，显式选择 X11 回归后端：

```bash
cmake --preset debug-x11
cmake --build --preset debug-x11
ctest --preset debug-x11
```

后端检查禁用用户 mpv 配置和脚本，使用空音视频输出，只验证创建、初始化、版本查询和销毁。环境探测到 Qt 6.12.0、mpv 0.41.0；pkg-config 的 mpv 2.5.0 是 client API 版本。

为规避 mpv 0.41.0 GPU 缩放 LUT 未初始化 padding 可能导致的 NaN，本应用显式将 `scale`、`cscale`、`dscale` 设为 `spline64`。该设置保留高质量重建滤镜，并覆盖放大、色度和缩小路径；mpv 上游已在后续版本修复 LUT padding。此兼容选项仍会覆盖用户缩放滤镜偏好，后续应基于运行时版本或实测决定是否移除。

CTest 自动生成包含音轨的彩色测试视频及无音轨版本，覆盖控制器、中文/空格路径、失败恢复、实际帧内容、菜单动作、定位预览、全屏恢复、隐藏/显示、GL 上下文重建和图形初始化失败。默认 `debug` 与 `sanitizers` 预设在原生 Wayland 运行窗口测试；`*-x11` 预设通过 Xvfb + Openbox 提供 CI 回归。Qt 的 offscreen 平台不能代替视频渲染检查。

测试使用 generic 主题和 compose 输入上下文隔离宿主 GTK/Fcitx 插件，音频使用 null 输出。正常启动仍使用桌面配置和真实音频输出；ASan/UBSan 与泄漏检查保持开启。`--smoke-test` 检查初始化和可选文件加载后自动退出。

打开文件会替换现有队列；添加文件、拖入一个或多个本地媒体文件、或传入多个命令行位置参数会追加或创建队列。网络地址及带主机名的 file URL（含 localhost）拖放会被拒绝并显示原因；本地文件请使用普通路径或无主机名的 file URL。全屏默认隐藏菜单与控制区，移动鼠标显示控制区，闲置后收起；错误会显示可见提示。正常播放禁用用户 mpv 配置、脚本、OSC 和默认键绑定，由 NekoPlayer 统一管理交互。

播放结束后自动进入下一项并跳过缺失文件；上一项按逆序跳过缺失文件。队列播完后追加媒体会启动新增项，暂停期间追加则保留当前播放。停止或播完后按空格可重新播放当前项。

播放列表可拖动单项重排，也可通过“播放列表”菜单或列表右键菜单移除、上移和下移所选项。选中项用于编辑，粗体项表示当前播放／待播项；进度更新不会抢回选择。移动条目或删除其他条目保持当前播放、暂停和位置；移除当前项会停止，并选取后一项（末项则选前一项），按空格后才播放，不删除磁盘文件。编辑后的顺序和当前行在正常退出时保存。

“文件”或“播放列表”菜单可打开和保存 UTF-8 M3U8。保存保留条目顺序、重复路径和当前行；本应用用标准注释 `#NEKOPLAYER-CURRENT:<行号>` 记录当前行，其他播放器会忽略此扩展注释。相对路径按播放列表文件所在目录解析，URL 条目按原样保留。打开前会完整校验文件，成功后替换队列并播放当前行；格式或读取错误不会改变当前队列。保存采用临时文件原子替换，失败时保留原播放列表文件。

“播放列表 → 播放模式”与右键菜单提供不循环、单曲循环和列表循环，也可按 R 依次切换。默认不循环且按列表顺序播放，循环模式只在本次运行保留。单曲循环只影响自然播完，手动上下项仍切歌；顺序列表循环的上下项及自然播完均支持首尾衔接。单曲及只有一项的列表使用 mpv 原生循环定位，保留音轨选择与外挂字幕；给单项列表追加媒体会恢复自动进入下一项。停止、清空和加载失败不会触发单曲重播；失败队列每行最多尝试一次，全部不可播放时结束，用户可再次显式播放来重试。

随机播放可从同一菜单或 Shift+R 独立开关，与循环模式组合，保留列表显示顺序及重复路径条目的独立身份。当前项视为本轮已访问，下一项从剩余条目中随机选择；不循环时一轮结束即停止，列表循环会开启新一轮，多项时避免轮次交界立即重复当前项。上一项沿实际访问历史回退，下一项先重走前向历史，再抽取新项；历史最多保留 1024 项。追加条目加入待播池，移动条目不打乱历史身份，删除当前项会停止并以邻项重新建立随机顺序。切换随机开关不重载媒体、不改变暂停和位置；显式选播或停止后重新播放会重新建立一轮。随机状态与历史仅在本次运行保留。

正常退出会保存播放列表、当前行及其播放位置、音量／静音、窗口大小和最大化状态、列表面板显示状态及媒体对话框目录。另有独立的 `<session path>.history.ini` 保存最近 100 个媒体文件的续播位置，切换文件、停止和正常退出时更新，媒体自然播完后删除该文件的历史；因此上次队列选中项之外的媒体也可在后续队列中续播。再次启动只恢复空闲队列，按空格才从上次位置继续；剩余不超过一秒时从头开始。会话续播位置只属于上次选中的条目，移动条目会保留，停止、清空、删除该条目或播放其他条目会取消；相同路径的重复条目独立处理。显式停止后的媒体不会在本次运行中从历史位置续播，但已保存的历史可在下次启动时恢复。命令行文件替换恢复队列。退出全屏时或在全屏下关闭，均保留之前的普通窗口状态，不在下次启动自动全屏。配置使用版本化 INI，Linux 默认位于 `$XDG_CONFIG_HOME/NekoPlayer/NekoPlayer/session.ini`（未设置时位于 `~/.config/` 下）；保存失败会提示，损坏或未知版本的配置不会被覆盖。`--no-config` 与 `--smoke-test` 均不读写配置。暂不提供轨道／外挂字幕持久化或崩溃恢复，也不检测同一路径的文件是否已被替换；同时运行多个实例时以最后保存的会话为准。

“声音 → 音轨”和“字幕”菜单可查看轨道编号、标题、语言、编码及当前选择，也可关闭音轨或字幕；右键菜单共用这些入口。加载外挂字幕后自动选中该轨道。切换轨道无需重新打开媒体，保持暂停状态；停止或换片时清空旧轨道。图形上下文重建时恢复音轨、字幕选择和已加载的外挂字幕。外挂字幕可通过文件对话框或单文件拖放加载，拖放识别 srt、ass、ssa、sub、vtt、sup、idx、mks（扩展名不区分大小写）。请先播放媒体，再单独拖入一个字幕文件；空闲时、一次拖入多个字幕或混合媒体与字幕会整体拒绝并提示，不修改播放列表。VobSub 的 idx/sub 配对请选择 idx，伴随文件交给 mpv 读取。其他扩展名沿用媒体追加行为，文件能否解析由 mpv 判断。

“字幕 → 字幕显示”提供显示开关、缩放与上下移动；隐藏仅控制可见性，保留轨道选择。F6 打开偏好设置并定位到字幕页；“设置”菜单也可从 F5 进入播放页。字幕页在未播放时也可打开，提供 0.25–4 倍缩放、0–100% 垂直位置和默认字体；100% 指原始位置，数值越小越靠上。对话框编辑为草稿，应用／确定才提交，恢复默认也需应用，取消保留已应用的修改。默认字体用于未指定字体的文本字幕，ASS 保留原样式，缩放／移动可能影响排版；位图字幕的效果取决于格式及 mpv 支持。偏好跨换片、停止及渲染恢复保留，正常退出保存，下次加载媒体前恢复。旧配置缺失或非法字段使用独立默认值，`--no-config` 不持久保存。字幕像素和真实字体效果尚待 Wayland 实机验收。

播放速度菜单提供 0.25–4 倍预设和自定义输入，并启用 mpv 音调修正。音频延迟范围为 ±10 秒，字幕延迟范围为 ±600 秒；正值延后、负值提前。菜单显示后端确认的值，快速连续按键累积调整。倍速和延迟跨停止、换片及渲染恢复保留，并在正常退出时写入会话配置、下次启动恢复；缺失或非法值分别回退到 1 倍和零延迟。`--no-config` 与 `--smoke-test` 不写入配置。

“视频”菜单与右键菜单提供原始比例、4:3、16:9、16:10、21:9 和拉伸填满；原始比例交给 mpv 读取媒体比例，拉伸会填满视频区域。Alt+←／Alt+→ 每次向左／向右旋转 90°，可从菜单重置旋转；旋转叠加在文件方向元数据上，重置仍尊重原始方向。菜单显示最新已提交的意图，后端执行失败会提示；比例提交失败后可重新选择比例恢复。比例与旋转在本次运行中跨停止、换片和渲染恢复保留，退出后恢复默认值。变换使用 mpv 原生选项，不新增 CPU 帧复制或视频滤镜，默认安全自动硬解保持不变；真实 Wayland 画面和硬解互操作效果尚待实机验收。

“视频 → 色彩调整”提供亮度、对比度、饱和度、色调和伽马，滑动时实时预览；“应用”更新取消回滚点，“确定”应用并关闭，“取消”恢复到上次应用值，恢复默认值也需应用或确定。五项使用 mpv 原生视频选项并限制在 -100 至 100，随会话在正常退出时保存、下次启动恢复；旧配置或非法值按零处理。该路径不复制解码帧到 CPU、不改变硬件解码偏好；本阶段只验证后端选项与会话行为，实际显示效果、HDR 兼容性及 Wayland/GPU 互操作尚待桌面验收。

“播放 → 定位”与右键菜单共用章节列表和时间输入。章节显示起始时间与标题，缺失标题时显示章节编号；选章及上下章保持暂停，不重新打开文件，首尾不会越界切换队列。Ctrl+G 接受秒数、分:秒或时:分:秒，可带最多三位小数；负数、非法格式与超过媒体时长的目标不可提交。时间请求精确到毫秒，最终显示帧仍由媒体时间戳决定，不承诺任意毫秒都有对应帧。不可定位的媒体会禁用这些操作。

同一“定位”菜单提供上一帧／下一帧，执行后暂停，可按空格恢复播放。只对当前选中的动态视频启用，纯音频、封面和静态图片禁用；后退还要求媒体可定位。使用 mpv 原生逐帧命令，后退可能从关键帧重新解码，在长 GOP 或部分滤镜／变帧率媒体上可能较慢或受限；按住快捷键不自动重复，避免累积昂贵定位。不改变硬解偏好或复制画面到 CPU。

“播放 → 定位 → A–B 区间循环”可将当前位置分别设为 A 和 B；设置两个端点后由 mpv 原生循环，B 必须晚于 A。可暂停后定位再设端点，操作不重载文件或改变暂停状态；菜单显示最新成功入队的区间，异步执行失败会提示，可清除后重试。区间只属于当前媒体，停止、换片或加载失败时清除，同一媒体的渲染恢复保留；不写入会话配置。循环范围外的手动定位遵循 mpv 语义，定位越过 B 会离开区间播放。该功能不新增进度轮询、CPU 帧复制或解码器。

“设置 → 偏好设置”及右键菜单的 F5 入口提供“自动（安全）”和“软件解码”，应用后立即切换，取消丢弃尚未应用的修改。音频页可选择输出设备，选择立即生效；右键菜单也保留快速设备菜单。自动模式默认请求 `hwdec=auto-safe`，不可用时由 mpv 回退；“实际解码器”独立显示观察到的结果。切换不重新打开媒体，但 mpv 可能重建解码器，画面会短暂中断。偏好在正常退出时保存，下次加载媒体前恢复；旧配置或非法字段默认自动模式。`--no-config` 不保存该偏好。真实 GPU 硬解效果尚未通过本阶段的非 GUI 测试验证。

“文件 → 媒体信息”、右键菜单或 Ctrl+F1 可查看当前文件的容器、字节大小、视频编码／尺寸／像素格式、容器帧率、音频编码／采样率／声道／采样格式与实际视频解码方式。窗口非模态，不暂停播放，可选中文本或按“复制”复制报告；换片及轨道变化自动更新。无法取得的参数显示“未知”，容器帧率是估计值，不代表实测输出帧率；文件大小来自 mpv 的媒体源长度，分段媒体不代表所有分段总大小。信息通过事件和解码配置变化后的异步查询更新，不定时轮询。

## 工程约束与验证边界

普通手写代码文件不超过 **500 行**。少数明确列入 `cmake/CheckCodeSize.cmake` 的窗口协调或桌面集成文件可不超过 **800 行**，新增例外必须附带理由；CTest 的 `code-size` 检查自动执行这两个限制。播放业务、GPU 资源、窗口协调与控制条分别实现，详见 [架构说明](docs/architecture.md)。使用 `clang-format`，警告默认开启；回调寿命变更必须运行 sanitizer 预设。

自动化以 Linux 原生 Wayland 为基准，并保留 Linux X11 软件 OpenGL 回归。当前实际验证为单个 1.75 缩放显示器；真实扬声器听感、音画同步、混合缩放多显示器、不同 GPU、硬解、HDR 与 Windows 尚需专项验收；不能由 null 音频或软件渲染测试推断。合成器可以使未聚焦的测试窗口 suspended，因此自动化通过共享 QAction 验证命令行为；真实 Wayland 键盘焦点/快捷键路由需要桌面手工验收。GL 上下文重建时重新打开当前本地文件并恢复时间和暂停状态，可能短暂中断播放。当前验证轮次按要求跳过 GUI 集成测试，详细证据见 [验证记录](docs/verification.md)。
