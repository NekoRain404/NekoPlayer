NekoPlayer for Windows
======================

Run NekoPlayer.exe. The directory is portable; configuration is stored under
%APPDATA%\NekoPlayer\NekoPlayer unless --no-config is passed.

This build bundles Qt 6, libmpv and FFmpeg DLLs. NekoPlayer is licensed under
GPL-3.0-only. The bundled libmpv/FFmpeg builds may include GPL components;
corresponding source and build information are available from the NekoPlayer
repository and the dependency projects.

Report issues at https://github.com/NekoRain404/NekoPlayer/issues
