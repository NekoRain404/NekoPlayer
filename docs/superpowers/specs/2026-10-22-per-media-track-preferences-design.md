# 按媒体恢复音轨与字幕选择

## 目标

让本地媒体在重新打开或应用重启后恢复用户最后选择的音轨和字幕轨道，包括用户加载的外挂字幕。该偏好与播放位置、全局字幕显示样式及音频输出设备分开保存；恢复失败不得阻止媒体播放或覆盖当前媒体的默认选轨。

## 范围

- 记录当前媒体最近一次已观察到的音轨选择和字幕选择（包含关闭状态）。
- 记录该选择需要的外挂字幕文件，并在媒体轨道初始化后按原顺序重新加载。
- 仅保存本地普通文件，最多保留最近使用的 100 个媒体配置；队列中的重复路径共享同一媒体配置。
- 仅在启动恢复和媒体轨道稳定后异步应用；用户在恢复期间主动选择轨道或加载字幕时，取消尚未完成的恢复。
- 保持当前全局字幕可见性、字体、缩放、位置和延迟偏好语义不变。

不实现全局语言优先级、同目录字幕自动扫描、字幕文件搜索、网络媒体持久化、崩溃恢复、媒体内容哈希或多实例合并。文件路径、大小或修改时间变化时不应用旧轨道配置。

## 媒体身份与数据

使用规范化绝对本地文件路径作为主键，并保存文件大小与修改时间作为轻量版本指纹。路径必须是存在的普通文件；缺失文件仍留在播放列表，但不读取或写入该文件的轨道配置。若相同路径的大小或修改时间与记录不一致，忽略旧轨道选择，并在下一次成功播放后以新指纹更新。

独立 `TrackPreferenceStore` 保存至 `<session path>.tracks.ini`，格式使用版本号、原子同步和与现有 history store 相同的防损坏覆盖策略。每条记录含规范化路径、文件指纹、最近使用时间、音轨标识、字幕标识及所需外挂字幕路径。按最近使用时间淘汰至多 100 条。解析失败或未知版本时保留文件原样、报告配置错误，并继续播放，不清空或覆盖旧数据。

内部轨道使用轨道类型和 mpv 轨道 ID；恢复时只在同类型内部轨道中匹配。外挂字幕选择使用规范化外挂字幕路径及同一路径下的流序号，不使用可能变化的 mpv 运行时轨道 ID。关闭状态与“没有保存过选择”必须可区分：没有记录时接受 mpv 默认选择；明确关闭时恢复为 0。

## 恢复流程

1. `FILE_LOADED` 后等待当前媒体的轨道快照可用，再按规范化路径和文件指纹读取配置。
2. 先异步加载记录中的外挂字幕路径，去重并保留保存顺序；不再存在或无法读取的路径跳过并报告一次非致命错误。
3. 轨道列表更新后按类型解析内部轨道 ID，外挂字幕按路径和流序号匹配；分别异步设置音轨和字幕轨道，包含 ID 0 的关闭状态。
4. 每个恢复请求关联媒体打开代数。换片、停止、失败或用户主动选择会使旧代数失效；迟到的回复不得修改新媒体状态或保存旧记录。
5. 两种轨道都确认后结束恢复抑制并更新最近使用时间。找不到保存的轨道时保留 mpv 当前选择，不循环重试；后续用户更改可以建立新记录。

渲染上下文重建沿用现有轨道快照恢复流程；新增的媒体偏好不应与 renderer recovery 重复加载字幕或相互覆盖。对同一媒体的 renderer reset，优先恢复内存中的完整快照；只有新媒体打开才查询持久记录。

## 保存流程

轨道快照在观察到选择变化后更新当前媒体记录；切换媒体前捕获旧媒体的最后快照，正常退出保存最终可用快照。保存过程不订阅进度、不在帧回调或 GUI 绘制期间执行，也不执行媒体扫描。应用通过现有异步 libmpv 命令和事件更新轨道，不改动解码器、GPU render API 或视频帧。

本地字幕文件路径以绝对路径持久化。若路径包含 NUL、不是本地绝对路径或超过现有配置字段安全上限，拒绝该记录并报告配置错误。外部文件恢复只使用记录的路径，不推导或扫描相邻文件。

## 架构与文件职责

- `TrackPreferenceStore` 及其值类型位于 `src/session/`，只依赖 Qt Core，负责版本化、规范化、有限容量和原子 INI 读写。
- `SessionManager` 协调当前媒体身份、播放控制器轨道快照和 store，负责生命周期捕获及恢复/保存错误汇总；不直接解析 mpv node。
- `MpvController` 暴露专用的异步媒体轨道恢复入口，复用已有 `MediaTrack` 快照、类型化选择命令、外挂字幕加载和请求代数；UI 不新增持久化逻辑。
- `mpvcontroller` 内的已有 renderer 恢复仍持有本次运行快照，不经磁盘 store。
- 普通手写代码文件不超过 500 行；必要时按 store、值类型、恢复协调器拆分，不扩大已登记 800 行例外。

## 验收

- 真实 headless libmpv 测试验证用户改变音轨／字幕后，保存并重建控制器可恢复实际选中轨道；字幕覆盖内嵌、外挂、关闭及多流外挂字幕。
- 重新打开同一文件可恢复，路径相同但大小或修改时间不同则不恢复；缺失外挂字幕、缺失轨道、缺失媒体、异步加载失败及损坏/未知版本配置都不阻止播放且不错误覆盖配置。
- 连续换片、停止、用户在恢复期间做出选择、同路径重复队列项及 renderer context recovery 不允许旧异步回复污染当前媒体或重复附加外挂字幕。
- 运行相关 headless 测试和会话／轨道回归，再运行 ASan/UBSan。窗口测试只构建不执行，遵从用户对窗口行为测试的要求。
- 运行完整 Debug 构建、格式检查、`git diff --check` 和 500/800 行限制检查；更新 README、architecture 与 verification 文档后提交该阶段。

## 设计自审

- 主键、文件版本指纹、持久格式和淘汰顺序均有明确规则。
- 无记录、明确关闭、媒体变更和轨道不可用分别定义，不会将旧轨道意图当作默认值。
- 恢复只在新媒体打开运行，renderer reset 继续用现存内存快照，避免重复外挂字幕加载。
- 字幕文件路径仅按记录恢复，不作目录扫描；错误不阻断播放。
- 测试覆盖真实后端选择、跨会话生命周期、错误配置及异步过期回复；桌面交互仍明确列为未验收。
